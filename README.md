# cmodels
The repository is collected from the codebase of SAT-based ASP solver [Cmodels](https://www.cs.utexas.edu/users/tag/cmodels/).

We used the codebase to compute clark completion of SharpASP-SR. Related publication: [ICLP25](https://www.cambridge.org/core/journals/theory-and-practice-of-logic-programming/article/counting-answer-sets-of-disjunctive-answer-set-programs/2695D99F659828956391D95B409E6448)
